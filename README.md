# Superstore Sales Analysis using SQL

## Objective

To perform exploratory data analysis on Superstore Sales and derive meaningful insights.

## Tools Used

- sqlite3
- Pandas
- Python

## Key Analysis

- Sales are concentrated in few major categories and sub-categories.
- Monthly sales trends suggest seasonal patterns.
- A small group of customers drives a large portion of sales.

## Dataset

Superstore Sales dataset from Kaggle
